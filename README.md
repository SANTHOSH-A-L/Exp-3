# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:
To design and develop a Railway Management System using UML diagrams to manage train schedules, passenger details, ticket booking, and ticket cancellation efficiently.
# SRS (Procedure):
Step 1: Problem Identification The main problem is the need for a simple and efficient system to manage railway activities such as train scheduling, passenger registration, ticket booking, cancellation, and checking train availability.

Step 2: Requirement Analysis Identify user needs (passenger and railway administrator). Define functional requirements: login, search train, check availability, book ticket, cancel ticket, view schedule, and manage train details. Define non-functional requirements: security, reliability, speed, accuracy, and usability.

Step 3: System Design Draw UML diagrams to represent the system:

Use Case Diagram Class Diagram Activity Diagram Sequence Diagram Communication Diagram Package Diagram

Design the database with tables for Passenger, Train, Station, Ticket, and Booking/Transaction.
